# OSN Photo Studio

تطبيق ويب (HTML + CSS + JS) يضع قالب نادي أولمبي الرياضي ندرومة وفلاتر رياضية وسينمائية على كل صورك دفعة واحدة، ثم يشاركها على فيسبوك من قائمة مشاركة الهاتف، ويُثبَّت كتطبيق (PWA) على أندرويد وآيفون.

## الفكرة
- يختار التطبيق **تلقائيًا أفضل صورة** (الأوضح والأفضل إضاءة وتباينًا وتأطيرًا) لتأخذ **غلاف TRAINING الكبير** (`cover.png`)، ويمكنك تغييرها بزر ⭐.
- كل الصور الأخرى تأخذ **القالب المينيماليست** (`minimal.png`). لكل صورة تصميم واحد فقط.
- بعد تعديل الصور يجهّز التطبيق النسخ النهائية في الخلفية، فيفتح زر **مشاركة كل الصور** قائمة مشاركة الهاتف فورًا بكل الصور (الغلاف أولًا)، فتختار فيسبوك دون ربط أي حساب.
- 48 فلترًا رياضيًا وسينمائيًا وتأثيرات، موزعة على أقسام، وكل فلتر يظهر على صورتك قبل اختياره (على الحاسوب: مرّر الفأرة لمعاينته). زر «قبل الفلتر» يقارن بالأصل.
- ضبط يدوي للشدة والسطوع والتباين والتشبع والدفء والحبيبات والحدة وتعتيم الأطراف.

## تغيير القوالب
ارفع PNG بوسط شفاف في خانة **غلاف مخصص** أو **مينيماليست مخصص** داخل التطبيق، أو استبدل الملفين `cover.png` و`minimal.png` في المستودع (يفضّل 1080×1440).

## النشر على GitHub Pages
Settings ← Pages ← Deploy from a branch ← `main` و`/ (root)`.

## التثبيت كتطبيق
- **أندرويد (Chrome):** زر **ثبّت التطبيق** في أعلى الصفحة، أو ⋮ ثم «تثبيت التطبيق».
- **آيفون (Safari فقط):** زر المشاركة ثم «إضافة إلى الشاشة الرئيسية». تحتاج المشاركة المباشرة iOS 15 أو أحدث.
- بعد التثبيت يعمل التطبيق بملء الشاشة وبدون إنترنت (الخط العربي يتحمّل في أول استخدام).
- عند رفع نسخة جديدة إلى GitHub يتحدّث التطبيق المثبّت تلقائيًا في المرة التالية التي يُفتح فيها.

## إن لم يعمل التطبيق بعد التحديث
- ارفع **كل** الملفات الخمسة عشر معًا إلى جذر المستودع (وليس بعضها فقط).
- يعرض التطبيق شريطًا أحمر في أعلى الصفحة يذكر الملف الناقص أو القديم. إن رأيته فارفع الملف المذكور ثم أعد فتح الصفحة.
- رقم الإصدار يظهر تحت اسم التطبيق («الإصدار 5»). إن لم يظهر فهذا يعني أن `index.html` في GitHub ما زال قديمًا.
- عند إصدار نسخة جديدة غيّر الرقم `5` في `index.html` و`app.js` و`sw.js` معًا.


## الإصدار 6
- الفلتر يُعاين على الصورة المعروضة فقط (سريع)، ثم زر «طبّق على الكل» في الأسفل يطبّقه على كل الصور.
- زر المشاركة يصبح «مشاركة» بعد التجهيز، وتظهر أخطاء المشاركة في شريط أحمر/أصفر، وخيار «عدد الصور في كل مشاركة» (إن رفض فيسبوك 10 صور قلّله)، وزر مشاركة لكل صورة.
- ارفع كل الملفات إلى GitHub (خاصة app.js و index.html و style.css و sw.js).
