# OSN Photo Studio

تطبيق ويب ثابت (HTML + CSS + JS) يضع قالب نادي أولمبي الرياضي ندرومة وفلاتر سينمائية على كل صورك دفعة واحدة، ثم يحمّلها في ملف ZIP.

## الملفات
- `index.html` الواجهة
- `style.css` التصميم
- `app.js` المنطق (القالب + الفلاتر + التصدير)
- `logo-data.js` شعار OSN المدمج (يُستخدم تلقائيًا في القالب)
- `crest.png` و`logo.png` و`favicon.png` صور الشعار وأيقونة التبويب

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلاً `osn-photo-studio`).
2. ارفع كل الملفات (`index.html`, `style.css`, `app.js`, `logo-data.js`, `crest.png`, `logo.png`, `favicon.png`, `README.md`) إلى الجذر.
3. من **Settings → Pages** اختر **Deploy from a branch**، الفرع `main`، المجلد `/ (root)`، ثم احفظ.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/osn-photo-studio/`

لا يحتاج أي تثبيت أو خادم. كل المعالجة داخل المتصفح والصور لا تُرفع لأي مكان.

## الاستخدام
1. اختر الصور (أو اسحبها).
2. عدّل نص القالب واللون وارفع الشعار (PNG شفاف).
3. اختر الفلتر وعدّل الشدة والحبيبات وتعتيم الأطراف.
4. اضغط **تحميل كل الصور (ZIP)**. كل 40 صورة ناتجة تُحفظ في ZIP مستقل لتفادي امتلاء الذاكرة.

## تخصيص
- الألوان الافتراضية: أعلى `app.js` (`INK`) وأزرار الألوان في `index.html`.
- فلاتر جديدة: أضف سطرًا في كائن `PRESETS` داخل `app.js`.
- خطوط جديدة: أضفها في رابط Google Fonts داخل `index.html` وفي كائن `FONTS` ثم في قائمة `#font`.
